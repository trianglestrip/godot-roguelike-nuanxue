# 新方向创意：暖雪式实时 + 五行流派

本文档与《暖雪》（Warm Snow）PC 版常见操作说明对齐，并在其上叠加 **五行 × 双分支**；实现见 [`src/realtime/`](../src/realtime/)。

---

## 1. 《暖雪》原作操作（参考）

以下摘自公开攻略中对 **PC 默认操作** 的归纳（左键近战、右键飞剑、空格瞬身、R 收剑、E 互动）：

| 输入 | 原作行为 |
|------|----------|
| **WASD** | 移动 |
| **鼠标左键** | 近战攻击 |
| **鼠标右键** | 发射 **飞剑** 远程伤害 |
| **飞剑落点** | 飞剑射出后会 **留在场上**（可理解为落地/插地），可走近拾取（本作原型未做「走路拾取」，以 **R 收剑** 为主） |
| **R** | **收剑**：在飞剑图标 **不在冷却** 时，收回 **全部** 飞剑；飞剑在 **收回轨迹上** 可再次造成伤害 |
| **空格** | **瞬身**（闪避位移） |
| **E** | 与道具、宝箱、圣物等 **互动**（本作即时原型未接关卡互动，可预留） |

**本作与原作差异（刻意设计）**：

- **无独立 Q/E 技能栏**；**怒气大招** 使用 **F**（不占 R，以便与暖雪「收剑=R」一致）。
- **五行切换 Tab**、**双分支 Z** 为扩展内容，原作无此映射。
- **场上飞剑上限**：参考「七剑」意象，原型设为 **最多 7 柄** 同时存在（`MAX_FLYING_SWORDS`）。

## 2. 本作默认键位（即时场景）

| 输入 | 行为 |
|------|------|
| **WASD** | 移动 |
| **鼠标左键** | 近战普攻（当前五行 + 当前分支） |
| **鼠标右键** | 发射 **五行飞剑**（像素条动画 + 命中/超时后 **插地停留**） |
| **R** | **收剑**：令场上飞剑 **飞回玩家**（路径伤害）+ **「五行返」范围爆发**（伤害与特效见姿态表，**有 CD**） |
| **空格** | **瞬身**（与 Shift 均可绑定闪避，便于习惯） |
| **Shift** | 同上，**闪避** |
| **F** | **怒气大招**（怒气满） |
| **Tab** / **Shift+Tab** | 切五行 |
| **Z** | 远程流 ↔ 近战流 |

## 3. 五行飞剑与收剑（差异化）

- **发射**：每种五行使用 **独立像素条**（`assets/realtime/projectiles/flying_sword_<metal|wood|water|fire|earth>.png`，每条约 **4 帧** 循环），并由 `element_color` 微调染色。
- **停留**：飞剑 **命中敌人** 或 **飞行超时** 后进入 **插地** 状态（静止帧），直至被 **R 收剑** 或新逻辑回收。
- **收回**：**R** 时所有飞剑进入 **飞向玩家** 状态，沿途可造成 **额外物理伤害**；同时触发 **范围魔法爆发**（与 `return_vfx`、`return_base` 一致）。

各系 **数值与分支名** 以 [`wuxing_skills_spec.md`](wuxing_skills_spec.md)、[`realtime_stance_defs.gd`](../src/realtime/realtime_stance_defs.gd) 为准。
